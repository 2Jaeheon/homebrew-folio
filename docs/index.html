  1. folio_list공고와 이력서 찾음

1분이면 설치 끝

  1. 터미널 열기

    Spotlight(⌘ 스페이스)에서 "터미널"을 찾아 열어요.

  2. 명령 붙여 넣기

    세 줄을 한 번에 붙여 넣으면 돼요. 가운데 brew trust는 이 저장소에서 받은 앱을 믿고 설치하겠다는 확인이에요.

    zsh — Homebrew로 설치 
    ❯ brew tap moduggagi/folio
❯ brew trust moduggagi/folio
❯ brew install --cask folio

  3. Folio 열기

    응용 프로그램 폴더에서 Folio를 열어요. 새 버전이 나오면 앱이 알아서 알려 주고 업데이트해요.

  1. 내려받기

    최신 버전 설치 파일을 받아요.

    Folio.dmg 내려받기

  2. 응용 프로그램으로 옮기기

    Folio.dmg를 열고, 창 안의 Folio를 응용 프로그램 폴더로 끌어다 놓아요.

  3. Folio 열기

    Apple 공증을 마친 앱이라 바로 열려요. 처음 열 때 묻는 창이 뜨면 열기를 누르세요. 그다음 업데이트는 앱이 알아서 해요.

macOS 26 이상. Apple Silicon과 Intel 모두 지원.

Folio는 내 Mac 안에서만 동작하는 이력서, 포트폴리오 보관함이에요.
